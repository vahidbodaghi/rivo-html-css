# Rivo Website

A responsive website built from scratch using HTML, CSS, and JavaScript.

## 🌐 Live Demo

[View Live Website](https://vahidbodaghi.github.io/rivo-html-css/)

## 📌 About

This project is a frontend practice project created to improve my web development skills and build a complete responsive website from scratch.

The project focuses on creating a clean layout, responsive design, and interactive elements using vanilla web technologies.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Responsive design
- Modern and clean UI
- Custom CSS styling
- Responsive footer
- Newsletter section
- Navigation and interactive elements
- Mobile-friendly layout

## 📱 Responsive Design

The website is designed to work across different screen sizes:

- Desktop
- Tablet
- Mobile
